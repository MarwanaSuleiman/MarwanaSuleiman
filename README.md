## Featured projects ✨

### 1. FlowPilot
A workflow orchestration platform for teams to automate repetitive tasks, monitor execution, and coordinate internal processes with minimal manual oversight.

- Built with: Next.js, TypeScript, PostgreSQL, Redis, Docker
- Highlights: dashboard analytics, task automations, user permissions, event tracking
- Status: Active development

### 2. Atlas Ledger
A lightweight financial reporting system designed for real-time visibility into budgets, expenses, and transactions across multiple departments.

- Built with: React, Express, PostgreSQL, Tailwind CSS
- Highlights: reporting pipelines, audit-friendly records, role-based views
- Status: Production-ready prototype

### 3. SignalBoard
A central notification and alerts dashboard for product operations, internal updates, and milestone-based communications.

- Built with: Node.js, FastAPI, MongoDB, WebSockets
- Highlights: live updates, alert routing, collaboration hooks
- Status: In optimization phase
